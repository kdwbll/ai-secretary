# 红米 / Xiaomi HyperOS 手机端使用指南

以下步骤适用于红米 Turbo 4 Pro。不同 HyperOS 版本的菜单名称可能略有差异。

## 1. 在电脑上启动服务

手机和电脑连接同一个可信 Wi-Fi。在项目目录执行：

```bash
.venv/bin/python -m uvicorn core.secretary.app:app --host 0.0.0.0 --port 8765
```

在 macOS 的“系统设置 → Wi-Fi → 当前网络 → 详细信息”查看电脑局域网 IP。假设是 `192.168.1.20`，手机端服务器地址就是：

```text
http://192.168.1.20:8765
```

打开电脑 Web 的“设置 → 设备安全”，点击“生成 6 位配对码”。配对码 5 分钟内有效且只能使用一次。在手机 App 的“设置”中填写服务地址和配对码，点击“保存并配对”。每台手机会获得独立令牌；不再使用时可在电脑端点“撤销”。不要把 8765 端口直接映射到公网。

## 2. 安装 Android 伴侣 App

开发版 APK 可以直接安装；当前本机构建产物位于 `artifacts/ai-secretary-0.4.0-debug.apk`。它使用 Android 调试证书签名，适合个人测试，不适合上传应用商店。

如果需要从源码重新构建：

1. 在电脑安装 Android Studio，并用它打开仓库中的 `android/` 目录。
2. 等待 Gradle 同步完成。
3. 手机进入“设置 → 我的设备/关于手机”，连续点击 OS 版本开启开发者模式。
4. 进入“设置 → 更多设置 → 开发者选项”，开启 USB 调试。
5. 用 USB 连接手机，在手机上允许这台电脑进行调试。
6. 在 Android Studio 选择这台手机，点击 Run 安装并启动 App。

也可以在 Android Studio 使用 Build APK(s) 生成调试 APK，再传到手机安装。首次侧载时，HyperOS 会要求允许当前文件管理器或浏览器安装未知应用。

## 3. 连接和授权

1. 打开“第二大脑”App。
2. 输入电脑地址，例如 `http://192.168.1.20:8765`。
3. 在电脑 Web 的“设置 → 设备安全”生成配对码，填入手机后点击“保存并配对”。
4. 同意短信读取和接收权限。
5. 点击“开启通知读取”，在系统页面找到“第二大脑”并打开通知使用权。
6. 返回 App，发送一条测试短信或收到一条通知，然后在电脑 Web 页面查看同步结果。

顶部“已联通”表示手机已经通过设备令牌成功访问电脑服务。仅能打开地址但没有完成配对时不会显示已联通。App 的四个页面分别用于：

- “会话”：查看手机和电脑的同一份聊天记录，实时收发消息，也可选择图片、视频和文档上传。
- “采集”：查看授权后新收到的短信和通知。
- “文件”：查看两个设备的上传记录、继续上传，或删除记录和电脑归档原件。
- “设置”：修改服务器地址并测试连接、开启通知读取权限。

短信内容和通知可能含验证码、消费、医疗等敏感信息。只授予确实需要的权限，并确保电脑和 Wi-Fi 可信。

## 4. 防止 HyperOS 停止后台同步

在手机设置中完成以下项目：

1. “设置 → 应用设置/应用 → 权限管理 → 后台自启动”，允许“第二大脑”自启动。
2. “设置 → 应用设置/应用 → 应用管理 → 第二大脑 → 省电策略/电量与性能”，选择“无限制”。
3. 打开最近任务，长按“第二大脑”卡片并点击锁形图标。
4. 不要开启超级省电；如果普通省电导致同步停止，也暂时关闭普通省电。

如果系统显示“受限设置”，请进入“第二大脑”的应用信息页，按系统提示允许受限设置，然后重新开启通知使用权。

## 5. 常见问题

- 手机打不开地址：确认电脑服务仍在运行、两台设备在同一个 Wi-Fi，地址使用电脑局域网 IP 而不是 `localhost`。
- 电脑能打开但手机不能：检查 macOS 防火墙是否拦截 Python，并允许局域网传入连接。
- 锁屏后不再同步：重新检查后台自启动、“无限制”和最近任务锁定。
- 没有短信：检查“应用信息 → 权限”中的短信权限。
- 没有通知：检查系统的“通知使用权”，这和普通通知权限不是同一个开关。
- 更换 Wi-Fi 后失效：电脑局域网 IP 可能变化，需要在 App 中更新并保存地址。
