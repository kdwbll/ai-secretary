# SecondBrain 0.14.0：审批、安全与可解释性

这个版本把后台动作统一纳入可持久化的安全策略。读取和草稿采用最小权限；外部写入及不可逆动作没有有效审批时无法进入执行阶段。

## 新增

- 统一 `read`、`draft`、`write`、`irreversible` 四级动作策略。
- Web 与 Android 审批中心：显示摘要、影响对象、精确内容和有效期，支持允许、编辑后允许、拒绝及撤销。
- 连接器权限页：分别管理邮箱、日历、短信、通知、位置、健康和文件权限，显示 scope 与最近使用时间。
- 撤销连接器后立即停止对应采集和未来事件任务，但保留已经采集的原始数据。
- 前后哈希链接的安全审计记录，可按日期、目标和连接器筛选并导出 JSON，也可检测记录被修改。
- 两阶段“完整遗忘”：先审批，再清理匹配记忆、派生索引和所选目标的未来任务。

## 安全保证

- 审批持久化到 SQLite，服务重启后不会丢失。
- 拒绝、过期、撤销或已消费的审批不能执行。
- 幂等键避免重复生成审批；同一审批只能被执行器原子领取一次。
- 当前邮箱、日历与 Android 数据源仍保持只读；本版本没有增加日历写入或邮件发送能力。

## 验证

- 136 项 Python 回归测试通过。
- 覆盖拒绝、过期、重复提交、服务重启、连接器撤销和审计篡改检测。
- Web 安全中心完成真实浏览器冒烟测试。
- Android v0.14.0 Debug APK 在 Android SDK 35 / JDK 17 下编译通过。

升级前会沿用既有数据库备份机制。数据库迁移到 schema 17，不会删除已有记忆、会话或采集数据。
