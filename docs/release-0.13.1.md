# SecondBrain 0.13.1：可靠后台执行与活动追溯

这是对已发布 0.13.0 调度器骨架的完成版，不移动旧标签，避免已下载文件与源码不一致。

## 完成内容

- 一次性和周期任务到期后会真正完成运行并留下结果，不再长期停在 `running`。
- 事件任务可订阅邮件、短信、通知、只读日历、文件分析和健康导入；只处理规则创建后的新事件。
- 每次运行使用唯一幂等键。服务重启会将遗留运行标记为中断并安全放回队列，不重复执行同一轮。
- Web 可配置手动、一次、周期和事件任务，可暂停单个后台任务，并查看运行状态、失败原因和下次计划。
- Android “活动与采集”页同时展示后台运行与原始采集记录，也可暂停或恢复后台任务。
- 主动通知支持上海时区免打扰、同原因 24 小时去重、同类合并，以及默认每日最多 3 条；被抑制的通知仍保留在历史中。

## 数据库升级

数据库结构升级到版本 16。升级前会按既有迁移机制创建备份；旧版程序不能打开升级后的数据库。

## 验证

- Python 全量测试：126 项通过。
- Android：JDK 17 离线执行 `assembleDebug` 成功。
- 覆盖到期执行、事件订阅水位、运行幂等、重启恢复、Asia/Shanghai 时区、通知 24 小时去重和每日上限。

## 兼容性

本版本只新增本地提醒型后台动作，不增加日历、邮件或其他外部系统写入能力。
