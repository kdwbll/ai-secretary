# 更新路线图

按安全基线、稳定性、记忆与性能、产品化四个阶段推进。共享改动同步到 main、win、android；平台打包和启动器保留在各自分支。

## 第二阶段：稳定性（2026-10-13，v0.8.1）

| ID | 状态 | 本次结果 |
| --- | --- | --- |
| REL-01 | 已完成 | 非流式调用的断连、超时、HTTP 和解析异常均记录 error；流式缺少完整结束信号记录 error；已有用量继续用于费用统计，连接前失败不计 Token。 |
| REL-02 | 已完成 | 可重试网络错误和 429/5xx 最多尝试三次；指数退避加随机抖动；支持秒数和 HTTP 日期 Retry-After；超过 10 秒的冷却不提前重试，返回失败或改用备用供应商；参数与鉴权错误立即返回。 |
| REL-03 | 已完成 | 网页和 Android 明确显示记忆保存失败，并支持只重试保存；成功完成的日记、事实和索引步骤有检查点，重试不重新调用模型。 |
| MAIL-01 | 已完成 | HTML 正文转纯文本，无纯文本部分时自动回退到 HTML；脚本、样式、图像及链接属性不会进入正文，也不下载跟踪像素；原有邮件附件继续归档。 |

记忆保存步骤的检查点记录在会话附件中。文件写入与 SQLite 不构成跨文件事务：若进程恰好在文件已写入、检查点尚未持久化时退出，仍可能需要人工核对；正常失败后的重试会跳过已完成步骤。

## 第三阶段：记忆与性能（2026-10-13，v0.8.2）

| ID | 状态 | 本次结果 |
| --- | --- | --- |
| MEM-01 | 已完成 | 按分句判断本人陈述、否定和条件；拒绝问题、他人说法和指令作为个人事实；否定偏好保留在“避让与不喜欢”；不确定、计划和一次经历进入 SQLite 待确认区，Web/Android 可确认或忽略，确认前不进入长期档案。 |
| PERF-01 | 已完成 | 迁移 10 添加持久化全文索引；保存、编辑、撤销立即更新对应文件；对话检索不遍历目录或全量读取 Markdown；目录清单只在新增/删除或摘要改变时重写；启动和每 15 秒后台检查外部改动，仅读取指纹发生变化的文件。 |

原始日记保留完整对话，但模型上下文明确区分原话与已确认事实。已有旧档案不自动改写；新的提取仍采用保守规则，不保证理解所有自然语言表达。索引是可重建的本机派生数据，Markdown 仍为原始记忆；后台扫描仍与文件数相关，但不在每轮对话中执行。
