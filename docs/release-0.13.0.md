# SecondBrain 0.13.0：后台执行与主动简报

本版本让目标中的任务可以由本机调度器持续推进，而不是只能手动勾选。

## 新增内容

- 任务支持手动、一次性和按分钟循环三种计划；循环任务成功后会自动排入下一次运行。
- 运行记录持久化到 SQLite，服务启动时会安全中断遗留运行并将任务放回队列；失败使用指数退避，达到上限后标记为“受阻”。
- 短信和通知入口使用内容指纹去重。移动端离线重传不会重复写入事件或重复触发解析副作用。
- 新增事件回执表和任务调度字段；升级旧数据库前会按既有迁移机制自动备份。
- 通知设置可配置免打扰时段和同类提醒合并窗口。关闭主动提醒不会删除通知历史；受阻和需要确认仍可以突破免打扰。

## 数据库升级

数据库将升级到结构版本 14。升级后的数据库不能由旧版本程序打开；请先完成本机数据备份，再回退到旧版。

## 已验证

- ` .venv/bin/python -m pytest -q`：121 项通过。
- 覆盖任务重试、失败阻塞、循环任务重排、事件幂等、通知合并及数据库迁移。

Android APK 需要 JDK 17 构建。发布前请执行 Android release 构建并将生成的 APK 与桌面安装包一起附加到 GitHub Release。
