# 第二大脑 v0.15.0 用户手册

适用版本：SecondBrain v0.15.0  
更新日期：2026 年 10 月 15 日  
技术支持：<wangzhoukang317@gmail.com>

## 1. 产品简介

第二大脑是一款在个人电脑上运行的 AI 助理。它可以保存可读的长期记忆，整理聊天、文件、邮件、短信、通知和只读日程，并帮助你持续推进目标。

v0.15.0 新增“行动与产物”工作台：

- 把日程建议送入审批，确认后创建本机日程记录；
- 保存并编辑本机邮件草稿；
- 使用健康复查、考试复习、旅行准备、账单订阅四类目标模板；
- 把回答整理为计划、清单、时间表或预算看板等 Artifact；
- 在电脑和 Android 手机上查看已批准日程、草稿和 Artifact。

第二大脑默认把数据保存在自己的设备上。AI 模型、联网搜索、地图和邮箱同步只有在你主动配置相应服务后才会使用网络。

## 2. 下载正确的安装包

请从 [v0.15.0 官方 Release 页面](https://github.com/kdwbll/ai-secretary/releases/tag/v0.15.0) 下载，不要使用来源不明的安装包。

| 设备 | 安装包 | 说明 |
| --- | --- | --- |
| Windows 11 | `SecondBrain-Setup-0.15.0.exe` | 64 位 Windows 安装程序 |
| Apple 芯片 Mac | `SecondBrain-macOS-arm64-0.15.0.dmg` | 适用于 M1、M2、M3、M4 等 Mac |
| Intel Mac | `SecondBrain-macOS-x86_64-0.15.0.dmg` | 适用于 Intel 处理器 Mac |
| Android | `SecondBrain-android-v0.15.0.apk` | 手机伴侣 App，需要电脑端服务配合 |

Android App 不能独立替代电脑端。手机采集、会话和行动内容都需要同步到已经启动并完成配对的电脑服务。

## 3. 安装与启动

### 3.1 Windows 11

1. 下载并双击 `SecondBrain-Setup-0.15.0.exe`。
2. 按安装向导完成安装；需要桌面图标时勾选创建桌面快捷方式。
3. 从开始菜单或桌面打开 SecondBrain。
4. 程序会在后台启动本机服务，并自动打开浏览器页面。

如果双击后没有网页：

1. 等待 10 秒后访问 <http://127.0.0.1:8765>；
2. 检查是否有安全软件阻止 `SecondBrain.exe`；
3. 查看日志：`%LOCALAPPDATA%\SecondBrain\second-brain.log`；
4. 把日志中的错误和系统版本发送到技术支持邮箱。

用户数据默认位于 `%LOCALAPPDATA%\SecondBrain`。正常升级或卸载程序不会自动删除这个目录。

### 3.2 macOS

1. 根据 Mac 处理器下载 ARM 或 Intel 版本的 DMG。
2. 打开 DMG，把 `SecondBrain.app` 拖到“应用程序”。
3. 从“应用程序”打开 SecondBrain，浏览器会自动显示工作台。

当前社区构建未经过 Apple 公证。如果系统阻止打开，请先确认文件来自本项目 Release 页面，然后前往“系统设置 → 隐私与安全性”，点击“仍要打开”。

用户数据和日志位于：

```text
~/Library/Application Support/SecondBrain
~/Library/Application Support/SecondBrain/second-brain.log
```

### 3.3 Android

1. 把 APK 下载到手机。
2. 根据系统提示，允许当前浏览器或文件管理器“安装未知应用”。
3. 安装并打开“第二大脑”。
4. 暂时不要授予不需要的权限；完成电脑配对后，再按功能需要授权。

小米、红米和 HyperOS 设备还需要设置后台自启动、电池策略和通知使用权，详见 [小米手机使用指南](android-xiaomi.md)。

## 4. 首次配置

### 4.1 确认服务状态

网页右上角会显示版本号和服务状态。正常状态应为：

```text
v0.15.0 · 核心服务在线
```

如果页面仍显示旧版本，请先在“设置 → 核心服务”终止旧服务，再从新安装的桌面程序重新启动。

### 4.2 配置 AI 模型

打开“设置 → 供应商”：

1. 选择供应商模板；
2. 填写显示名称、接口地址、API Key 和模型名称；
3. 点击“保存供应商”；
4. 在“任务路由”中分别选择文字、图片和视频处理模型。

API Key 只用于本机服务请求模型。网页接口不会重新返回密钥明文。模型调用可能产生费用，请以供应商账单为准。

不配置模型时，文件保存、记忆浏览和部分规则功能仍可使用，但 AI 对话和分析能力会受限。

### 4.3 完成初始采访

在“今日”页点击“开始 5 分钟采访”。建议填写：

- 常用称呼；
- 工作或学习方向；
- 当前目标；
- 时间安排和偏好；
- 不希望系统记录的内容。

这些信息会成为后续回答、早报和建议的本地上下文。记忆文件可以在“记忆”页查看和编辑。

## 5. 手机与电脑配对

### 5.1 准备网络

手机和电脑必须连接同一个可信 Wi-Fi。不要把 8765 端口直接映射到公网。

电脑地址应填写电脑的局域网 IP，例如：

```text
http://192.168.1.20:8765
```

不要在手机上填写 `localhost` 或 `127.0.0.1`，它们代表手机自身。

### 5.2 生成配对码

1. 在电脑网页打开“设置 → 设备安全”；
2. 点击“生成 6 位配对码”；
3. 在 5 分钟内把电脑地址和配对码填入 Android App；
4. 点击“保存并配对”；
5. 手机顶部显示“已联通”即表示成功。

配对码只能使用一次。每台手机拥有独立设备令牌；不再使用某台手机时，可在电脑网页撤销该设备。

## 6. 日常功能

### 6.1 今日与早报

“今日”页汇总近期日程、重要提醒、个人建议和项目动态。点击“重新生成”可以使用当前最新数据生成简报。

默认定时任务使用 Asia/Shanghai 时区：

- 07:30 早报；
- 22:30 晚间复盘；
- 周日每周整理。

### 6.2 对话

在“对话”页输入问题，也可以附加图片、视频或文档。手机与电脑共享聊天记录。

AI 给出多个明确选项时，界面会显示可点击按钮和“其他”输入项。多个问题会依次引导，先完成当前问题，再进入下一个问题。

每条 AI 回复下方的“保存为 Artifact”可以把内容转为长期维护的工作产物。

### 6.3 目标与模板

“目标”页支持普通目标，也提供四种模板：

- 健康复查：准备资料、预约并设置复查提醒；
- 考试复习：拆分范围、每日复习和模拟检查；
- 旅行准备：整理行程、预订信息和出发前检查；
- 账单订阅：整理费用、设置周期检查并确认是否续订。

模板只创建目标、任务和触发规则，不会替你进行付款、预约或外部写入。

### 6.4 文件与收件箱

“收件箱”支持图片、视频、PDF、Word、Excel、CSV、文本和 ZIP 等文件。

- 原件保存在电脑本地并按哈希去重；
- 图片和视频分析需要相应的视觉模型；
- Office、PDF 和文本优先在本机提取内容；
- 点击“安全预览”时，脚本、外部图片、框架和网络资源会被阻止；
- 删除文件会同时删除上传记录和本机归档原件，执行前请确认。

### 6.5 邮件、短信、通知和日历

邮件连接器使用 IMAP 只读同步。QQ、163 等邮箱应填写授权码，不要填写邮箱登录密码。

短信、系统通知和 Android 系统日历必须在手机上明确授权：

- 日历权限为只读，仅同步近期日程到电脑；
- 验证码、应用运行提示等垃圾通知会按规则过滤；
- 手机离线时数据进入本地队列，重新连接后继续同步；
- 小米/HyperOS 应把 App 电池策略设为“无限制”。

### 6.6 地图

地图功能需要在“设置 → 位置与地图”配置高德地图 Key。

- JS API Key 和 `securityJsCode` 用于显示地图卡片；
- Web 服务 API Key 用于 AI 查询地点和周边信息；
- 位置不会随每次对话自动读取，只有主动授权或保存后才会使用。

## 7. v0.15 行动与产物

### 7.1 日程建议

在“行动与产物 → 日程建议”填写标题、开始时间、结束时间、地点和备注。

1. 点击“检查冲突并申请”；
2. 系统显示与本机日程、Android 只读日程的时间冲突；
3. 打开“审批与安全”；
4. 检查将要保存的准确内容；
5. 点击“允许”；
6. 点击“创建已批准的本机日程”。

拒绝同一建议后，系统不会反复创建相同审批。编辑时间或内容时应重新确认冲突。

重要边界：v0.15.0 只创建第二大脑内部的本机日程记录，不会写入 Google 日历、Outlook、Apple 日历或 Android 系统日历。

### 7.2 邮件草稿

在“行动与产物 → 邮件草稿”填写收件人、主题和正文。

- 草稿只保存在电脑本地；
- 可以继续修改或删除；
- Android“行动”页可以查看草稿；
- v0.15.0 不会发送邮件，也没有后台自动发送能力。

发送前请把草稿复制到自己的邮箱客户端，并再次检查收件人、附件和内容。

### 7.3 Artifact

Artifact 是可以持续维护的结构化工作产物，包括：

- 计划；
- 清单；
- 时间表；
- 预算看板。

可以在“行动与产物”直接创建，也可以从对话回复保存。Artifact 可关联目标，并记录来源、更新时间和版本号。

打开 Artifact 后可以：

- 编辑内容并保存为新版本；
- 使用隔离的安全预览；
- 导出 Markdown，预算看板也可导出 CSV；
- 删除 Artifact。

系统会阻止旧版本覆盖新版本。AI 也不会在未经确认时覆盖你手动编辑过的内容。删除 Artifact 不会删除原始对话、目标或记忆。

## 8. 审批与安全

“审批与安全”页用于集中处理写入和不可逆操作。

每张审批卡会显示：

- 动作等级；
- 目标连接器；
- 影响对象；
- 有效期；
- 将要处理的准确 JSON 内容。

在允许前请认真检查内容。可以直接拒绝、撤销，或在允许前修改准确内容。批准并不总是等于已经执行；例如本机日程仍需点击一次“创建已批准的本机日程”。

撤销连接器权限会停止后续同步和相关任务，但不会自动删除已经采集的数据。安全审计可以导出为 JSON。

## 9. 暂停、终止和关闭浏览器

关闭浏览器标签页不会关闭后台服务。定时任务和手机同步仍会继续运行。

在“设置 → 核心服务”中：

- “暂停服务”：停止聊天、同步、上传和定时任务，可在同一页面恢复；
- “终止服务”：完全关闭后台，需要再次运行桌面启动器才能启动。

安装新版前建议先终止旧服务，再退出旧应用并安装新版。

## 10. 数据、备份和隐私

重要数据包括：

- `memory/`：可读的 Markdown 长期记忆；
- `files/`：归档原件；
- `data/second-brain.db`：设置、索引、会话、任务、审批和审计记录。

建议定期备份整个用户数据目录，并在备份前先终止服务，避免复制到正在写入的数据库。

请注意：

- 向云端 AI 提问时，当前问题和相关上下文会发送给你配置的模型供应商；
- 联网搜索只在开启且问题需要最新信息时使用；
- 本版本不提供完整的数据文件加密，不要把用户数据目录同步到不可信的公共空间；
- 健康图表只用于个人记录，不构成医疗建议。

## 11. 升级到新版

1. 备份用户数据目录；
2. 在网页“设置 → 核心服务”点击“终止服务”；
3. 下载与设备匹配的新安装包；
4. Windows 直接运行新版安装程序；macOS 用新版 App 替换“应用程序”中的旧版；Android 可覆盖安装新版 APK；
5. 重新启动后确认网页右上角版本号；
6. 检查手机是否仍显示“已联通”。

数据库会按顺序自动迁移。不要在升级过程中强制关机，也不要手动删除数据库迁移记录。

## 12. 常见问题

### 网页打不开

- 访问 <http://127.0.0.1:8765>；
- 确认没有另一个旧版本占用 8765 端口；
- 重新运行桌面启动器；
- 查看 `second-brain.log`。

### 网页能打开，但按钮都不能使用

- 查看右上角是否显示“核心服务已暂停”；
- 刷新页面并确认版本号为 v0.15.0；
- 清除该站点缓存后重新打开；
- 如果服务已经终止，必须重新运行桌面启动器。

### 手机显示未联通

- 确认手机和电脑在同一个 Wi-Fi；
- 使用电脑局域网 IP，不要使用 `localhost`；
- 重新生成一次性配对码；
- 检查电脑防火墙是否允许 SecondBrain；
- Wi-Fi 变化后重新确认电脑 IP。

### 手机通知或短信延迟

- 开启通知使用权和短信权限；
- 允许后台自启动；
- 把电池策略改为“无限制”；
- 在最近任务中锁定 App；
- 返回 App 设置页执行通知扫描并查看最近捕获、最近上传时间。

### 手机看不到地图卡片

- 确认电脑已保存高德 JS API Key、`securityJsCode` 和 Web 服务 Key；
- 检查高德控制台的 Key 类型和域名白名单；
- 确认手机网络可以访问高德地图资源；
- 在对话中重新提出明确的位置或周边查询。

### 日程没有写入手机系统日历

这是 v0.15.0 的设计边界。本版本只读 Android 系统日历，并在审批后创建第二大脑本机日程记录，不写入手机或外部日历。

### 邮件草稿没有发送

这是正常行为。本版本只保存本机草稿，任何邮件都不会自动发送。
