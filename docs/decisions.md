# 设计决策

## 2026-10-10：Web 前端采用无构建依赖的 HTML/CSS/JavaScript

当前目标设备没有 Node.js，而产品要求本机可运行。Web UI 因此直接由 FastAPI 托管静态文件，不引入 React 构建链。界面仍保持响应式、可访问和模块化；以后若交互复杂度显著增加，可迁移到 React。

## 2026-10-10：Python 最低版本兼容 3.9

规格推荐 3.11+，当前设备为 3.9.6。核心代码避免使用 3.10+ 专属语法，使用户无需先升级即可运行；持续集成仍应覆盖 3.11 和 3.12。

## 2026-10-10：AI 未配置时使用确定性本地降级

首次启动不强制 API Key。记忆选择、短信解析、搜索和基础回答可离线工作；配置 OpenAI 兼容供应商后，smart/fast 路由自动接管。这样不会因为模型失败而丢数据。

## 2026-10-10：向量检索先以可替换的词法检索实现

M5 的“按意思搜索”通常需要下载嵌入模型或依赖外部 API。当前实现提供统一搜索接口与本地词法排序，后续可在不改 UI/API 的情况下替换为 sqlite-vec。

## 2026-10-10：Android 高权限采集保持显式授权

短信、通知、相册和健康数据均不得静默开启。Android 工程提供短信接收、通知监听、系统分享和 WorkManager 离线同步基础设施；权限请求、局域网配对和 Health Connect 需在真实 Android SDK 环境中完成设备级联调。
